IPGlance 1.1.0

  • New: country kill switch — blocks outgoing traffic via the macOS firewall (pf) when your public IP leaves the countries you allow, and lifts the block automatically when it's back.
  • Asks for the administrator password once; can be removed any time in Settings → "Remove system rules…".
  • Refreshed menu: status line with kill switch state and last check time, Copy IP / Refresh buttons, collapsible recent IPs.
  • Settings are now a native tabbed window and apply instantly; About moved into Settings.
  • Like IPGlance? There's a Buy Me a Coffee link in the menu.
  • The menu now shows the real app version.
